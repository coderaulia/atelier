# SEO & SSR Prerendering Guide

## Core Principles
1. **Zero Hydration Mismatch**: Static HTML generated by prerender scripts (`scripts/prerender.mjs`) must cleanly hydrate with client-side React without flashing or DOM layout differences.
2. **Canonical and OpenGraph Accuracy**: Every public page (marketing, tool landing pages, templates) must render unique `<title>`, `<meta name="description">`, `og:image`, and `rel="canonical"` tags.
3. **Structured Data (Schema.org)**: Add valid JSON-LD tags (`WebApplication`, `SoftwareApplication`, `HowTo`) to improve rich snippet search indexation.
4. **i18n & Hreflang Alignment**: Ensure localized routes (`/id/`, `/en/`) specify proper `hreflang` links and alternate language headers.

## 1. Prerendering Pipeline (`scripts/prerender.mjs`)

### Build Workflow
The build script generates static HTML files for all public marketing routes:
```bash
# 1. Build client bundle and SSR entry point
npm run build:ssr

# 2. Execute prerender script to output static HTML pages
npm run prerender
```

## 2. Meta Tags & Schema Standards

### A. Dynamic Document Meta Helper
```typescript
interface PageSEOProps {
  title: string;
  description: string;
  canonicalPath: string;
  ogImage?: string;
  lang?: 'en' | 'id';
}

export function generateSEOMetadata({ title, description, canonicalPath, ogImage, lang = 'en' }: PageSEOProps) {
  const fullUrl = `https://app.vanaila.com${canonicalPath}`;
  const fullOgImage = ogImage || 'https://app.vanaila.com/og-default.png';

  return {
    title: `${title} | Atelier by Vanaila`,
    meta: [
      { name: 'description', content: description },
      { property: 'og:title', content: title },
      { property: 'og:description', content: description },
      { property: 'og:url', content: fullUrl },
      { property: 'og:image', content: fullOgImage },
      { property: 'og:type', content: 'website' },
      { name: 'twitter:card', content: 'summary_large_image' },
      { name: 'twitter:title', content: title },
      { name: 'twitter:description', content: description },
      { name: 'twitter:image', content: fullOgImage },
    ],
    links: [
      { rel: 'canonical', href: fullUrl },
      { rel: 'alternate', hrefLang: 'en', href: `https://app.vanaila.com/en${canonicalPath}` },
      { rel: 'alternate', hrefLang: 'id', href: `https://app.vanaila.com/id${canonicalPath}` },
      { rel: 'alternate', hrefLang: 'x-default', href: fullUrl },
    ]
  };
}
```

## 3. SEO Quality & Verification Checklist
- [ ] Unique `<h1>` per page matching target keywords.
- [ ] All images have descriptive `alt` tags and explicit `width`/`height` or aspect-ratio to prevent CLS.
- [ ] Dynamic OpenGraph preview images exist and resolve to valid absolute URLs.
- [ ] Robots.txt allows search crawlers on `/` and `/tools/*`, while disallowing private `/app/*` user workspace paths.
- [ ] Sitemap (`sitemap.xml`) includes all public routes with appropriate `lastmod` timestamps.
